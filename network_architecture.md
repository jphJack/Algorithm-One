# VIBE双模态生物特征识别网络架构文档

## 1. 概述

VIBE（Vein and Palm Print Biometric Enhancement）网络是一个基于掌纹和掌静脉双模态的生物特征识别系统。该网络采用双层递进式混合专家（MoE）架构，通过多频域特征提取和跨模态融合机制，实现高精度的个人身份识别。

### 1.1 任务描述
- **目标**：基于掌纹和掌静脉图像判断个人身份
- **支持数据集**：HandsData (290类)、CASIA (200类)、QH (500类)、TJ (600类)、CUMT2 (532类)
- **数据集**：每人5张训练图像和5张测试图像

### 1.2 数据规格
| 模态 | 原始图像尺寸 | 预处理后尺寸 | 光源类型 | 通道数 |
|------|-------------|-------------|----------|--------|
| 掌纹 | 190×217 | 128×128 (可配置) | 可见光 | 3 (RGB) |
| 掌静脉 | 180×180 | 128×128 (可配置) | 红外光 | 3 (RGB) |

### 1.3 数据增强策略
训练时对掌纹和掌静脉图像应用**同步几何变换**和**独立颜色增强**：
- **同步几何变换**：随机裁剪（相同位置）、随机旋转（相同角度，±15°）
- **颜色抖动**：亮度 ±0.2、对比度 ±0.2、饱和度 ±0.2、色调 ±0.1
- **归一化**：ImageNet 均值 [0.485, 0.456, 0.406]，标准差 [0.229, 0.224, 0.225]

## 3. 模块详细设计

### 3.1 双支流骨干网络 (DualStreamBackbone)

骨干网络采用轻量化CNN架构，分别处理掌纹和掌静脉图像。两个支流具有独立参数，以适应不同模态的特征分布。每个支流输出 Stage 3、4、5 的多尺度特征图，通过 MultiScaleFeatureExtractor 融合为统一特征。

#### 3.1.1 单支流骨干网络结构 (LightweightBackbone)

```
输入: [B, 3, H, W]
    │
    ▼
┌─────────────────────────┐
│ Stage 1: Conv(3→32, s=2)│  → [B, 32, H/2, W/2]
│         Conv(32→32)     │
└───────────┬─────────────┘
            │
            ▼
┌─────────────────────────┐
│ Stage 2: Conv(32→64, s=2)│ → [B, 64, H/4, W/4]
│         Conv(64→64)      │
└───────────┬─────────────┘
            │
            ▼
┌─────────────────────────┐
│ Stage 3: Conv(64→128, s=2)│ → [B, 128, H/8, W/8]  ← 输出
│         Conv(128→128)    │
└───────────┬─────────────┘
            │
            ▼
┌─────────────────────────┐
│ Stage 4: Conv(128→256, s=2)│ → [B, 256, H/16, W/16] ← 输出
│         Conv(256→256)    │
└───────────┬─────────────┘
            │
            ▼
┌─────────────────────────┐
│ Stage 5: Conv(256→256, s=2)│ → [B, 256, H/32, W/32] ← 输出
│         Conv(256→256)    │
└───────────┬─────────────┘
            │
            ▼
输出: features = {3: [B,128,H/8,W/8], 4: [B,256,H/16,W/16], 5: [B,256,H/32,W/32]}
```

每个卷积块 (ConvBlock) 包含：
- Conv2d (kernel_size=3, bias=False)
- BatchNorm2d
- ReLU (inplace=True)

每个 Stage 包含 2 个 ConvBlock：第一个 stride=2 进行空间下采样，第二个 stride=1 精炼特征。

#### 3.1.2 多尺度特征提取器 (MultiScaleFeatureExtractor)

```
输入: features = {3: [B,128,H/8,W/8], 4: [B,256,H/16,W/16], 5: [B,256,H/32,W/32]}
    │
    ├─────────────────────────────────────────────────────────────┐
    │                                                             │
    ▼                                                             ▼
┌─────────────────────┐                               ┌─────────────────────┐
│ Reducer (Stage 3)   │                               │ Reducer (Stage 4)   │
│ Conv1×1(128→64)     │                               │ Conv1×1(256→64)     │
│ BN + ReLU           │                               │ BN + ReLU           │
│ → [B,64,H/8,W/8]    │                               │ → [B,64,H/16,W/16]  │
└──────────┬──────────┘                               └──────────┬──────────┘
           │           ┌─────────────────────┐                    │
           │           │ Reducer (Stage 5)   │                    │
           │           │ Conv1×1(256→64)     │                    │
           │           │ BN + ReLU           │                    │
           │           │ → [B,64,H/32,W/32]  │                    │
           │           └──────────┬──────────┘                    │
           │                      │                               │
           │                      │ Upsample → [B,64,H/8,W/8]     │
           │                      │                               │
           │           ┌──────────┘              Upsample → [B,64,H/8,W/8]
           │           │                                    │
           └───────────┼────────────────────────────────────┘
                       │
                       ▼
           ┌─────────────────────────┐
           │ Concat → [B, 192, H/8, W/8]│
           └───────────┬─────────────┘
                       │
                       ▼
           ┌─────────────────────────┐
           │ Conv1×1(192→256)        │
           │ BN + ReLU               │
           │ Conv3×3(256→256)        │
           │ BN + ReLU               │
           └───────────┬─────────────┘
                       │
                       ▼
输出: [B, 256, H/8, W/8]
```

**Reducer**：1×1 卷积将各 Stage 特征通道统一为 reducer_channels (64)，然后上采样到 Stage 3 的分辨率后拼接，经两层卷积投影到 feature_dim (256)。

```
输入: print_img [B,3,H,W], vein_img [B,3,H,W]
    │
    ├──────────────────────────────────────┐
    │                                      │
    ▼                                      ▼
┌───────────────────┐          ┌───────────────────┐
│ print_backbone    │          │ vein_backbone     │
│ (Lightweight)     │          │ (Lightweight)     │
│ → print_features  │          │ → vein_features   │

```

### 3.2 MoE特征增强模块 (MoEEnhancement)

该模块为每种模态构建独立的专家网络池，包含三个并行专家：高频专家、中频专家和低频专家。门控网络根据输入特征动态生成权重，加权融合三个专家的输出。模块内置负载均衡损失，防止专家坍塌。

#### 3.2.1 高频信息处理专家 (HighFreqExpert)

用于提取边缘、纹理等高频特征。

```
输入: [B, C, H, W]
    │
    ├──────────────────────────────────┐
    │                                  │
    ▼                                  ▼
┌─────────────────┐           ┌─────────────────┐
│ 拉普拉斯核卷积   │           │ 细节增强块1     │
│ (固定参数3×3)   │           │ (深度可分离卷积) │
│ [[0,1,0],       │           │ + 逐点卷积      │
│  [1,-4,1],      │           │ + BN + ReLU     │
│  [0,1,0]]       │           │ + 残差连接)     │
│ 逐通道卷积      │           └────────┬────────┘
└────────┬────────┘                    │
         │                             ▼
         │                    ┌─────────────────┐
         │                    │ 细节增强块2     │
         │                    │ (结构同上)      │
         │                    └────────┬────────┘
         │                             │
         └──────────┬──────────────────┘
                    │ (逐元素相加)
                    ▼
           ┌─────────────────┐
           │  1×1 Conv + BN  │
           └────────┬────────┘
                    │
                    ▼
输出: F_HF [B, C, H, W]
```

**细节增强块 (DetailEnhanceBlock) 结构**：
```
输入 → Depthwise Conv(3×3, groups=C) → Pointwise Conv(1×1) → BN → ReLU → (+输入残差) → 输出
```

#### 3.2.2 中频信息处理专家 (MidFreqExpert)

用于提取多尺度上下文信息和方向性纹理特征。

```
输入: [B, C, H, W]
    │
    ├───────────────────────────────────────┐
    │                                       │
    ▼                                       ▼
┌─────────────────────┐           ┌─────────────────────┐
│ 多尺度空洞卷积分支   │           │ 方向感知卷积分支     │
│ (ASPP)              │           │                     │
│                     │           │                     │
│ Branch1: Conv1×1    │           │ Conv(1×7, C→C/2)   │
│   C → C/4           │           │ Conv(7×1, C→C/2)   │
│ Branch2: Conv3×3    │           │                     │
│   d=2, C → C/4      │           │ Concat → [B,C,H,W] │
│ Branch3: Conv3×3    │           │ Conv1×1(C→C)       │
│   d=4, C → C/4      │           │ BN + ReLU          │
│                     │           └──────────┬──────────┘
│ Concat → [B,3C/4]   │                      │
│ Conv1×1 → C         │                      │
│ BN + ReLU           │                      │
└──────────┬──────────┘                      │
           │                                 │
           └──────────┬──────────────────────┘
                      │ (逐元素相加)
                      ▼
           ┌─────────────────────┐
           │  + 输入 (残差连接)  │
           └──────────┬──────────┘
                      ▼
           ┌─────────────────────┐
           │  1×1 Conv + BN      │
           └──────────┬──────────┘
                      ▼
输出: F_MF [B, C, H, W]
```

#### 3.2.3 低频信息处理专家 (LowFreqExpert)

用于提取整体轮廓、光照分布等低频特征。

```
输入: [B, C, H, W]
    │
    ├───────────────────────────────────────┐
    │                                       │
    ▼                                       ▼
┌─────────────────────┐           ┌─────────────────────┐
│ 编码器-解码器分支    │           │ 低通滤波分支         │
│                     │           │                     │
│ Depthwise Conv(7×7) │           │ AvgPool(5×5)        │
│ + Pointwise Conv    │           │ stride=1, padding=2 │
│ + BN + ReLU         │           └────────┬────────────┘
│ → skip_feat         │                    │
│                     │                    │
│ MaxPool(2×2)        │                    │
│ → [B,C,H/2,W/2]     │                    │
│                     │                    │
│ Bottleneck:         │                    │
│ Conv3×3 + BN + ReLU │                    │
│                     │                    │
│ Upsample(×2)        │                    │
│ Concat(skip_feat)   │                    │
│ → [B,2C,H,W]        │                    │
│ Conv1×1(2C→C)       │                    │
│ BN + ReLU           │                    │
│ → F_dec             │                    │
└──────────┬──────────┘                    │
           │                               │
           │    F_dec                      │   F_lp
           └──────────┬────────────────────┘
                      │
                      ▼
           ┌─────────────────────┐
           │ α × F_dec +         │
           │ (1-α) × F_lp        │  ← α 为可学习参数 (初始 0.5)
           └──────────┬──────────┘
                      ▼
           ┌─────────────────────┐
           │  1×1 Conv + BN      │
           └──────────┬──────────┘
                      ▼
输出: F_LF [B, C, H, W]
```

#### 3.2.4 门控网络 (GateNetwork)

```
输入: [B, C, H, W]
    │
    ▼
┌─────────────────────┐
│ AdaptiveAvgPool2d(1) │
│ → [B, C]            │
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│ FC(C → C/4)         │
│ ReLU                │
│ FC(C/4 → 3)         │
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│ Softmax(dim=-1)     │
│ → [w1, w2, w3]      │
└──────────┬──────────┘
           │
           ▼
输出: 专家权重 [B, 3]
```

#### 3.2.5 MoE特征增强模块整合

```
输出 = w1 × F_HF + w2 × F_MF + w3 × F_LF
```

#### 3.2.6 负载均衡损失 (Load Balancing Loss)

```
L_lb = N_experts × Σ(f_i²) - 1

其中 f_i = mean(weights[:, i]) 为第 i 个专家的平均门控权重
```

该损失鼓励门控网络均匀分配样本到各专家，防止某个专家被过度使用（专家坍塌）。

### 3.3 MoE融合模块 (MoEFusion)

该模块构建跨模态交互专家池，包含三个异构专家：跨注意力融合专家、多尺度卷积融合专家和通道交互融合专家。双模态联合门控网络根据两种模态的特征动态生成权重。

#### 3.3.1 跨注意力融合专家 (CrossAttentionExpert)

基于交叉注意力机制，利用双向注意力捕捉双模态特征的全局语义关联。

```
输入: F_p [B, C, H, W], F_v [B, C, H, W]
    │
    ├──────────────────────────────────────────────────┐
    │                                                  │
    ▼                                                  ▼
┌───────────────────────────┐           ┌───────────────────────────┐
│ 掌纹→静脉注意力            │           │ 静脉→掌纹注意力            │
│                           │           │                           │
│ Q_p = Conv1×1(C→C/8)      │           │ Q_v = Conv1×1(C→C/8)      │
│ K_v = Conv1×1(C→C/8)      │           │ K_p = Conv1×1(C→C/8)      │
│ V_v = Conv1×1(C→C)        │           │ V_p = Conv1×1(C→C)        │
│                           │           │                           │
│ Reshape: [B, HW, C/8]     │           │ Reshape: [B, HW, C/8]     │
│                           │           │                           │
│ Attn = Softmax(Q_p @ K_v^T)│          │ Attn = Softmax(Q_v @ K_p^T)│
│ Cross_p2v = V_v @ Attn^T  │           │ Cross_v2p = V_p @ Attn^T  │
│ Reshape: [B, C, H, W]     │           │ Reshape: [B, C, H, W]     │
└─────────────┬─────────────┘           └─────────────┬─────────────┘
              │                                       │
              └──────────────────┬────────────────────┘
                                 │
                                 ▼
                    ┌───────────────────────────┐
                    │ Concat([F_p, F_v,         │
                    │        Cross_p2v,         │
                    │        Cross_v2p])        │
                    │ → [B, 4C, H, W]           │
                    └─────────────┬─────────────┘
                                  │
                                  ▼
                    ┌───────────────────────────┐
                    │ Conv1×1(4C → C) + BN      │
                    └─────────────┬─────────────┘
                                  │
                                  ▼
                    ┌───────────────────────────┐
                    │ + 0.5 × (F_p + F_v)       │  ← 残差连接
                    └─────────────┬─────────────┘
                                  │
                                  ▼
输出: [B, C, H, W]
```

#### 3.3.2 多尺度卷积融合专家 (MultiScaleConvExpert)

采用不同感受野的并行卷积核，聚焦局部微观特征的互补性。

```
输入: F_p [B, C, H, W], F_v [B, C, H, W]
    │
    ▼
┌───────────────────────────┐
│ Concat([F_p, F_v])        │
│ → [B, 2C, H, W]           │
└─────────────┬─────────────┘
              │
              ▼
┌───────────────────────────┐
│ Conv1×1(2C → C) + BN + ReLU│
└─────────────┬─────────────┘
              │
              ├──────────┬──────────┐
              │          │          │
              ▼          ▼          ▼
        ┌─────────┐┌─────────┐┌─────────┐
        │Conv 1×1 ││Conv 3×3 ││Conv 5×5 │
        │C → C    ││C → C    ││C → C    │
        └────┬────┘└────┬────┘└────┬────┘
             │          │          │
             └──────────┼──────────┘
                        │ (逐元素相加)
                        ▼
              ┌─────────────────────┐
              │  Conv1×1(C→C) + BN  │
              └──────────┬──────────┘
                         │
                         ▼
输出: [B, C, H, W]
```

#### 3.3.3 通道交互融合专家 (ChannelInteractionExpert)

通过通道注意力机制实现模态间的特征交互与校准。

```
输入: F_p [B, C, H, W], F_v [B, C, H, W]
    │                              │
    ▼                              ▼
┌─────────────────┐      ┌─────────────────┐
│ GlobalAvgPool   │      │ GlobalAvgPool   │
│ → [B, C]        │      │ → [B, C]        │
└────────┬────────┘      └────────┬────────┘
         │                        │
         │    global_p            │    global_v
         │                        │
         ▼                        ▼
┌─────────────────┐      ┌─────────────────┐
│ MLP_v(global_v) │      │ MLP_p(global_p) │
│ FC(C→C/4)       │      │ FC(C→C/4)       │
│ ReLU            │      │ ReLU            │
│ FC(C/4→C)       │      │ FC(C/4→C)       │
│ Sigmoid         │      │ Sigmoid         │
│ → weights_p     │      │ → weights_v     │
│ [B,C,1,1]       │      │ [B,C,1,1]       │
└────────┬────────┘      └────────┬────────┘
         │                        │
         ▼                        ▼
┌─────────────────┐      ┌─────────────────┐
│ F_p × weights_p │      │ F_v × weights_v │
│ (静脉校准掌纹)  │      │ (掌纹校准静脉)  │
└────────┬────────┘      └────────┬────────┘
         │                        │
         └──────────┬─────────────┘
                    │ (逐元素相加)
                    ▼
          ┌─────────────────────┐
          │  Conv1×1(C→C) + BN  │
          └──────────┬──────────┘
                     │
                     ▼
输出: [B, C, H, W]
```

#### 3.3.4 融合门控网络 (FusionGateNetwork)

```
输入: F_p [B, C, H, W], F_v [B, C, H, W]
    │                    │
    ▼                    ▼
┌──────────────┐  ┌──────────────┐
│ GlobalAvgPool│  │ GlobalAvgPool│
│ → [B, C]     │  │ → [B, C]     │
└──────┬───────┘  └──────┬───────┘
       │                 │
       └────────┬────────┘
                │
                ▼
    ┌─────────────────────┐
    │ Concat → [B, 2C]    │
    └──────────┬──────────┘
               │
               ▼
    ┌─────────────────────┐
    │ FC(2C → C/2)        │
    │ ReLU                │
    │ FC(C/2 → 3)         │
    └──────────┬──────────┘
               │
               ▼
    ┌─────────────────────┐
    │ Softmax(dim=-1)     │
    │ → [w1, w2, w3]      │
    └──────────┬──────────┘
               │
               ▼
输出: 融合专家权重 [B, 3]
```

#### 3.3.5 MoE融合模块整合

```
输出 = w1 × F_cross_attn + w2 × F_multiscale + w3 × F_channel
```

融合模块同样包含负载均衡损失，计算方式与特征增强模块一致。

### 3.4 分类网络 (Classifier)

采用 ArcFace (Additive Angular Margin) 判别头，增强类间可分性。

```
输入: [B, C, H, W]
    │
    ▼
┌─────────────────────────┐
│ AdaptiveAvgPool2d(1)    │
│ → [B, C, 1, 1]          │
│ → view → [B, C]         │
└───────────┬─────────────┘
            │
            ▼
┌─────────────────────────┐
│ Linear(C → embed_dim)   │  embed_dim = 256
│ (bias=False)            │
└───────────┬─────────────┘
            │
            ▼
┌─────────────────────────┐
│ BatchNorm1d(embed_dim)  │
└───────────┬─────────────┘
            │
            ▼
┌─────────────────────────┐
│ Dropout(p=0.5)          │
└───────────┬─────────────┘
            │
            ▼
┌─────────────────────────────────────────┐
│ ArcMarginProduct                        │
│                                         │
│ 1. L2 Normalize(embedding)              │
│ 2. L2 Normalize(weight)                 │
│ 3. cosine = embedding @ weight^T        │
│ 4. 对目标类别施加角度惩罚:               │
│    phi = cos(θ + m)                     │
│    m = 0.5 (角度惩罚)                   │
│ 5. output = s × (one_hot×phi +          │
│            (1-one_hot)×cosine)          │
│    s = 30.0 (缩放因子)                  │
└────────────────────┬────────────────────┘
                     │
                     ▼
输出: [B, num_classes]
```

**ArcFace 关键参数**：
| 参数 | 值 | 说明 |
|------|-----|------|
| s (scale) | 30.0 | 特征缩放因子，控制 logits 的幅度 |
| m (margin) | 0.5 | 角度惩罚，增强类间距离 |
| embed_dim | 256 | 嵌入向量维度 |

## 4. 训练策略

### 4.1 损失函数

总损失由三部分组成：

```
L_total = L_ce + λ_lb × (L_lb_enhance_p + L_lb_enhance_v + L_lb_fusion)
```

| 损失项 | 说明 | 权重 |
|--------|------|------|
| L_ce | 交叉熵损失 + Label Smoothing (0.05) | 1.0 |
| L_lb_enhance_p | 掌纹增强模块负载均衡损失 | 0.01 |
| L_lb_enhance_v | 静脉增强模块负载均衡损失 | 0.01 |
| L_lb_fusion | 融合模块负载均衡损失 | 0.01 |

### 4.2 优化器与学习率

| 配置项 | 值 |
|--------|-----|
| 优化器 | AdamW |
| 初始学习率 | 1e-4 |
| 最小学习率 | 1e-6 |
| 权重衰减 | 1e-4 |
| Warmup | 5 epochs (线性增长) |
| 衰减策略 | Cosine Annealing |
| 梯度裁剪 | max_norm = 1.0 |

### 4.3 训练超参数

| 配置项 | 值 |
|--------|-----|
| Batch Size | 32 |
| Epochs | 100 |
| 随机种子 | 42 |
| 确定性模式 | True |
| Label Smoothing | 0.05 |
